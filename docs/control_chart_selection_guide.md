# Control Chart Selection Guide

| Situation | Recommended chart |
|---|---|
| One continuous measurement per time point | I-MR chart |
| Continuous data collected in small subgroups | X-bar/R chart |
| Continuous subgrouped data with SD preferred | X-bar/S chart |
| Fraction nonconforming, variable sample size | p-chart |
| Count nonconforming, constant sample size | np-chart |
| Count of defects, constant opportunity | c-chart |
| Defects per unit, variable opportunity | u-chart |
| Simple visual trend without control limits | Run chart |

## Important note

Control limits are not specification limits. Control limits describe process behavior; specification limits define acceptance requirements.
